## 二、实际学习与实践

### 1. open() 与 close()

- 使用 `open()` 打开普通文件。
- 使用 `O_WRONLY | O_CREAT | O_TRUNC` 创建或清空文件。
- 检查 `open()` 的返回值。
- 使用 `close()` 关闭文件。
- 理解文件描述符从 3 开始分配的常见情况。

### 2. 文件读取

- 使用 `O_RDONLY` 打开文件。
- 使用 `read()` 读取文件内容。
- 使用 `write()` 输出读取到的数据。
- 根据 `read()` 返回值区分正常读取、EOF 和读取失败。

### 3. 文件描述符复用实验

- 连续调用三次 `open()`。
- 记录返回的文件描述符。
- 关闭第一个文件描述符。
- 再次调用 `open()`。
- 观察 Linux 对最小可用文件描述符的复用行为。

实验结果：

    3
    4
    3

### 4. 文件打开标志实验

使用不同的标志完成文件创建、清空、追加和读取。

- `O_CREAT`：创建文件。
- `O_TRUNC`：清空原文件内容。
- `O_APPEND`：追加写入。
- `O_RDONLY`：读取文件。

实验文件：

    flag_test.txt

预期文件内容：

    First line
    Second line

### 5. 错误处理练习

- 检查 `open()` 是否返回 -1。
- 检查 `write()` 是否返回 -1。
- 检查 `read()` 的正数、零和负数情况。
- 在发生错误时关闭已经成功打开的文件描述符。
- 根据程序执行结果使用非零退出码表示失败。
