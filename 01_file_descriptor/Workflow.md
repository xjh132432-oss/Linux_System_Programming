# Day 01 学习流程记录

## 一、学习内容

1. 认识文件描述符（FD）的概念。
2. 学习标准输入、标准输出、标准错误及其编号 0、1、2。
3. 学习 read() 的参数、返回值和基本使用方法。
4. 学习 write() 的参数、返回值和基本使用方法。
5. 对比 read() 与 write() 的数据流向。
6. 使用 read() 和 write() 实现终端输入输出。

## 二、实践记录

### 1. 标准文件描述符

认识 STDIN_FILENO、STDOUT_FILENO、STDERR_FILENO 三个宏，以及它们对应的数字 0、1、2。

### 2. write() 独立练习

独立编写程序，定义三个字符数组：

- linux
- System Programming
- File Descriptor

使用 write() 分别输出三条内容，并保存返回值。

实际观察到的返回值：

| 内容 | 返回值 |
|---|---:|
| linux | 5 |
| System Programming | 18 |
| File Descriptor | 15 |

理解 STDOUT_FILENO 与数字 1 等价。

### 3. read() 与 write() 综合练习

独立编写终端输入回显程序。

实现内容：

- 定义 100 字节字符缓冲区。
- 使用 write() 输出输入提示。
- 使用 read() 从标准输入读取数据。
- 根据 read() 返回值判断读取结果。
- 使用 write() 输出缓冲区中的实际读取内容。

## 三、学习成果

- 理解文件描述符的基本概念。
- 掌握标准文件描述符 0、1、2。
- 能独立编写基本的 read() 调用。
- 能独立编写基本的 write() 调用。
- 理解缓冲区容量与实际读取长度的区别。
- 能够组合 read() 和 write() 实现基本终端输入输出。
